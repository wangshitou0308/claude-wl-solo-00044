# 民乐考级 · 纸件与赴考脚注核对

面向**同时带兄妹参加社会艺术水平民乐考级**的家长：把考点公开简章里的脚注逐条录入，
再登记两个孩子的已有证书、曲目、纸件材料状态和同行安排，系统按公告依据核对，
生成按孩子、按装袋顺序排列的勾选清单和当天时间带。

## 本机运行

需要 Python 3.10+（开发环境 3.11，目标 3.12），仅依赖 Flask：

```bash
pip install flask
python seed.py          # 可选：灌入一份示例简章 + 一对兄妹（含典型冲突）
python app.py           # 启动后浏览器打开 http://127.0.0.1:5000
```

数据全部保存在本机同目录的 `kaoji.db`（SQLite），无外网依赖。
重置示例：`python seed.py --reset`
规则测试：`python tests.py`

## 使用流程（四个页签）

1. **简章脚注**：逐条录入乐种、级别、跳级凭证、照片规格、纸表签章、证件份数、
   候考时段、入口开放、跨入口步行时间。每条都有“公告依据编号”（如 TJ-01、ZP-01）。
   拿不准的条款勾“含不明项”，相关结论会保留为**待确认**而不是擅自判定。
   公告改版时点“据当前版改版”，复制出新版本后逐条修订，**旧结论立即全部失效**。
2. **孩子与材料**：填每名孩子的报考级别/跳级起点、候考时段、入口；登记已有证书
   （是否持有原件）、曲目（跳级加试）、同行成人陪护时段。点“按当前简章生成/校准清单”
   后逐项设置材料状态、份数、占用的原件名与交验时段地点。
3. **核对结论**：每条结论分 不通过 / 待确认 / 提醒 / 通过 四档，**逐条附公告依据编号**。
4. **装袋清单与时间带**：
   - SVG 时间带画出两个孩子的候考、成人陪护、原件交验条、入口开放竖线，
     跨兄妹的原件/成人连线在赶不到时变红，并用红色三角标出**当天最早冲突点**；
   - 每个孩子一张装袋清单（☐ 勾选、状态、份数、占用原件、公告依据），可打印/另存 PDF。

## 核查规则

| 类别 | 核查内容 |
| --- | --- |
| 报考资格 | 乐种是否开考、级别是否在简章范围 |
| 跳级条件 | 跳报级别是否被跳级条款覆盖；证书乐种/级别是否达到要求、是否有原件；加试曲目是否登记并练成 |
| 字段矛盾 | 纸表所填姓名、乐种、级别、准考证号等与报考登记逐字段比对；签字/盖章是否齐全 |
| 材料缺漏 | 简章要求的纸表/照片/复印件/跳级凭证是否齐备、份数与底色是否符合 |
| 原件占用 | 同一原件（如户口本原件、某级证书）被兄妹两份材料同时占用时：同刻异地=不通过；先后使用时按 route 条款的步行分钟算转送是否来得及 |
| 兄妹候考 | 同一成人在两个入口的陪护时段重叠=分身冲突；先后陪护时按跨入口步行时间算转场余量 |
| 入口开放 | 到达时刻早于入口开放时刻=进不去；路线未录步行时间=待确认 |

## 失效原则

每次核对都会对“简章条款”和“报考/材料数据”分别计算指纹。
之后任一者变化，历史结论在页面上自动盖上“已失效”戳并提示重新核对；
简章版本被替换后，旧版结论一律标记为“旧版结论”。历史核对记录保留留档。
